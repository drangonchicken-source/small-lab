소개와 광고 안내

작은 실험실은 AI와 표·문서를 함께 쓰는 사람이 결과를 넘기기 전에 확인할 것을 실험으로 찾아 기록합니다.

자료의 성격

이 사이트의 실험은 모두 직접 만든 가상 자료를 Python 표준 기능으로 실행한 결과입니다. 실제 고객 자료를 쓰지 않았고, 특정 앱의 동작이나 AI의 오류율을 측정하지 않았습니다. 실행 기록은 자동으로 페이지로 옮겼고 문장을 덧붙여 꾸미지 않았습니다.

광고

이 사이트에는 카카오 애드핏 광고가 표시됩니다. 광고는 "광고"라고 표시된 자리에만 나오며, 본문 내용은 광고주와 무관합니다.
